<h1>InvProbMeter</h1>
<p>Автономна система екологічного моніторингу на основі нейромережевого розв'язування оберненої задачі для дробово-диференціального рівняння адвекції-дифузії із супутниковою передачею даних</p>
<p>Даний репозиторій містить повний вихідний код клієнтьскої та серверної частини проєкту, а також скрипти для самостійного тренування нейромережевого розв'язувача</p>
<h2>Клієнтська частина</h2>
<ul>
  <li><b>sketch/sketch.ino</b> - код прошивки мікроконтролера, що реалізує збір даних з датчиків та передачу їх на сервер для інференсу моделі розв'язувача. Для коректної роботи необхідна плата з підтримкою WIFI. Реалізовано 2 режими роботи: Передача даних по WIFI (режим налагодження) та через супутникову мережу Iridium. Необхідні компоненти наведено в кінці документа</li>
</ul>
<h2>Серверна частина</h2>
<ul>
  <li><b>model.py</b> - містить реалізацію згорткової мережі з transformer-енкодером та трьома повнозв'язними головами регресії для ефективного визначення просторових, фізичних та часових ознак навіть у зашумленому сигналі. Для часового параметру використовується пулінг з механізмом уваги для точного виокремлення піків сигналу.</li>
  <li><b>inference.py</b> - реалізація інференсу моделі для неперервної обробки вхідних даних за допомогою кільцевого буфера. Оскільки нейронна мереже приймає на вхід масив із 720 вимірювань, для забезпечення виконання обчислень в реальному часі обробник слідкує за тим, щоб інференс розпочинався одразу після надходження сигналу, що перевищує порогове значення концентрації. У разі початку витоку менше ніж через 2 години, буфер заповнюється зліва тишею та останніми зафіксованими значеннями швидкості та напрямку вітру.</li>
  <li><b>main.py</b> - реалізація точки входу на сервері за допомогою FastApi для прийому даних з Arduino та відправки назад результатів обчислення</li>
</ul>
<h2>Самостійне тренування та тестування нейромережевого розв'язувача</h2>
<ul>
  <li><b>generate.py</b> - скрипт для автоматичної генерації датасету довільного розміру за прямою моделлю напіваналітичної схеми розв'язку дробово-диференціального рівняння адвекції-дифузії з кусково-сталими коефіцієнтами швидкості вітру у форматі .h5. Можна також завантажити готовий датасет за посиланням: <a href="https://drive.google.com/file/d/14Pg-j7J6CudlvJ_iuG48NPljAiJqP1yW/view?usp=drive_link">Google Drive</a></li>
  <li><b>train.py</b> - повний пайплайн тренування нейромережі за алгоритмом AdamW. Реалізовано ліниве завантаження датасету, скедулер для атоматичного зниження Learning Rate при виході на плато та вивід MAE, Train Loss та Validation Loss Для кожної епохи. Повертає файли ваг та скейлерів, які можна розмістити на сервері. Для роботи скрипта необхідно мати файл датасету та model.py</a></li>
  <li><b>simulation.py</b> - скрипт, що імітує повний двогодинний цикл інференсу моделі та будує порівняльні графіки істиних значень та передбачення моделі. Для роботи необхідні модулі generate.py та inference.py</li>
</ul>

<h2>Список компонентів для складання пристрою-клієнта</h2>
<ul>
  <li>Arduino UNO R4 WIFI</li>
  <li>Датчики летких органічних сполук MISC-5524</li>
  <li>I2C-дисплей 20x4</li>
  <li>Анемометр ZTS-3000-FSJT</li>
  <li>Флюгер PR-3000-FXJT</li>
  <li>Блок живлення на 12V</li>
</ul>
<p>Зауваження 1: у разі підключення дисплею до пінів SCL та SDA на платі необхідно використовувати аналоговий мультиплексор, оскільни піни A4 та A5 та піни I2C апаратно пов'язані між собою. Для використання пінів A4-A5 на вихід необіхдно підключити дисплей через qwiic-порт на платі, попередньо узгодивши логічні рівні до 3.3V.</p>
<p>Зауваження 2: живити анемомтр і флюгер слід від стороннього джерела живлення 12-24V, інакше сенсори заберуть на себе усе живлення мікроконтролера.</p>
<p>Зауваження 3: сенсори газу слід розмістити у формі тетраедра дла забеспечення уловлювання просторового градієнту газової хмари. Готовий датасет передбачає розміщення сенсорів навершинах тетраедра з висотою 19 см, у разі використання власних пропорцій слід згенерувати власний датасет.</p>
